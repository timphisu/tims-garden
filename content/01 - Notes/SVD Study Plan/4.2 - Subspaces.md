# Subspaces

> [!definition]
> A [[Subsets|subset]] $W$ of a vector space $V$ is called a **subspace** of $V$ if $W$ is itself a vector space under the addition and scalar multiplication defined on $V$. 

## Subspace Test

### Intuition

Essentially, a subspace is a defined vector space within another defined vector space. In order for this "subspace" to be a defined vector space, it must satisfy all [[Vector Space Axioms|axioms]]. For 8 of the 10 Axioms, they always hold since they *inherit* those properties from $V$. However, for Axioms 1 and 6, they require that vectors in $W$ that add and (scalar) multiply should result as vectors that stay in $W$.
;
### Definition

> [!theorem] Subspace Test
> If $W$ is a nonempty set of vectors in a vector space $V$, then $W$ is a subspace of $V$ if and only if the following conditions are satisfied. 
> 
> * (a) If $\mathbf{u}$ and $\mathbf{v}$ are vectors in $W$, then $\mathbf{u} + \mathbf{v}$ is in $W$. 
> 
> * (b) If $k$ is a scalar and $\mathbf{u}$ is a vector in $W$, then $k\mathbf{u}$ is in $W$. 

> Note that we should first confirm the set $W$ is nonempty before applying the Subspace Test.
