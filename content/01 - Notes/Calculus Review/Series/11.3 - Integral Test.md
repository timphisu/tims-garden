
# Integral Test

> [!theorem] Integral Test
> Suppose $f$ is a continuous, positive, decreasing function on $[1, \infty)$ and $f(n) = a_{n}$. Then the series $\sum_{n=1}^{\infty} a_{n}$ is convergent if and only if the improper integral $\int_{1}^{\infty} f(x) \, dx$ is convergent.


> [!note] Notes about the Integral Test
> 
> 1. $f$ does not have to be always decreasing but ultimately decreasing, that is $\exists N \in [1, \infty)$ such that $f'(x) < 0$ for $x > N$. 
> 2. Our lower bound does not have to start at $n=1$, if $\sum_{n=N+1}^{\infty} a_{n}$ is convergent then $\sum_{n=1}^{N} a_{n} + \sum_{n=N+1}^{\infty} a_{n}$ is also convergent.

## Proof of the Integral Test

Suppose we graph the curve of $f$ and draw $n$ rectangles to approximate the area underneath $f$. Each rectangle has a base length of $1$, that is the interval $[i, i+1]$ for $1 \leq i \leq n$, and a height of $f(i+1)$, or evaluated at the right-end point: It follows that then the area for each rectangle is $a_{i}$. 

Graphically, this looks like

![[Pasted image 20260629180545.png]]


Comparing the areas of the shaded rectangles with the area under $y = f(x)$ from $1$ to $n$, we see that

$$
a_{2} + a_{3} + \cdots + a_{n} \leq \int_{1}^{n} f(x) \, dx 
$$

> This inequality depends on the fact that $f$ is decreasing

Likewise, if we picked rectangles evaluated at the left-end point, which looks like

![[Pasted image 20260629181052.png]]

We'd get 

$$
\int_{1}^{n} f(x) \, dx \leq a_{1} + a_{2} + \cdots + a_{n-1}
$$


If $\int_{1}^{\infty} f(x) \, dx$ is convergent, then 

$$
\sum_{i=2}^{n} a_{i}  \leq \int_{1}^{n} f(x) \, dx \leq \int_{1}^{\infty} f(x) \, dx 
$$

so long as $f(x) \geq 0$. Therefore

$$
s_{n} = a_{1} + \sum_{i=2}^{n} a_{i} \leq a_{1} + \int_{1}^{\infty} f(x)\, dx = M
$$

Since $s_{n} \leq M$ for all $n$, the sequence $\{ s_{n} \}$ is bounded above. Also that

$$
s_{n+1} = s_{n} + a_{n+1} \geq s_{n}
$$

since $a_{n+1} = f(n+1) \geq 0$. Thus $\{ s_{n} \}$ is an increasing bounded sequence and converges by the Monotonic Sequence Theorem. This means that $\sum a_{n}$ is convergent.

If $\int_{1}^{\infty} f(x) \, dx$ is divergent, then $\int_{1}^{n} f(x)\, dx \to \infty$ as $n \to \infty$ because $f(x) \geq 0$. But recall that

$$
\int_{1}^{n} f(x)\, dx \leq \sum_{i=1}^{n-1} a_{i}
$$

and so $s_{n-1} \to \infty$. This implies that $s_{n} \to \infty$ and so $\sum a_{n}$ diverges.

## Introduction to P-Series

> [!theorem]
> The $p$-series $\sum_{n=1}^{\infty} {1}/{n^{p}}$ is convergent if $p > 1$ and is divergent if $p \leq 1$

A result from Euler is the $p$-series where $p = 2$

$$
\sum_{n=1}^{\infty} \frac{1}{n^{2}} = \frac{1}{1^{2}} + \frac{1}{2^{2}} + \frac{1}{3^{2}} + \cdots = \frac{\pi^{2}}{6} 
$$


> [!warning]
>  It can be easy to get a value from the Integral Test and straight away assume that it is the sum of the series. A counterexample to this belief is the above series where $\int_{1}^{\infty} \frac{1}{x^{2}}\, dx = 1$ does not equate to $\sum {1}/{n^{2}} = {\pi^{2}}/{6}$. In general, $\sum_{n=1}^{\infty} a_{n} \ne \int_{1}^{\infty} f(x) \, dx$.

Another useful result from Euler is 

$$
\sum_{n=1}^{\infty} \frac{1}{n^{4}} = \frac{1}{1^{4}} + \frac{1}{2^{4}} + \frac{1}{3^{4}} + \cdots = \frac{\pi^{4}}{90}
$$

which will be useful for later reference since we now know the series $\sum {1}/{n^{2}}$ and $\sum {1}/{n^{4}}$ are convergent while the series $\sum {1}/{n}$ is divergent.

**Problem:** Determine whether the series $\displaystyle \sum_{n=1}^{\infty} \frac{\ln(n)}{n}$ is convergent or divergent.

**Approach:** For $x > 1$, the function $\displaystyle f(x) = \frac{\ln(x)}{x}$ is positive and is continuous. To get a better idea if $f$ is decreasing or not, we take the first-derivative and solve for when $f'(x) < 0$

$$
f'(x) = \frac{1 - \ln(x)}{x^{2}} < 0  \implies 1 < \ln(x) \implies x > e
$$

Although $f'(1) > 0$, we find that $f$ is increasing when $x > e$. 

We can now take the Integral Test

$$
\int_{1}^{\infty} \frac{\ln(x)}{x}\, dx = \lim_{ t \to \infty } \left[ \frac{1}{2}(\ln x)^{2} \right]_{1}^{t} = \frac{1}{2} \lim_{ t \to \infty } (\ln(t))^{2} = \infty
$$

Since $\int_{1}^{\infty} f(x)\, dx$ diverges, the series should diverge as well.

## Estimating the Sum of a Series

Suppose we know that $\sum a_{n}$ is convergent. We might be able to approximate the sum $s$ by adding up $n$ terms, that is by using $s_{n}$. However, we want to know how accurate this approximation is by estimating the size of the **remainder**, denoted $R_{n}$.

$$
R_{n} = s - s_{n} = a_{n+1} + a_{n+2} + a_{n+3} + \cdots
$$

Using the same ideas from the Integral test, assuming that $f$ is decreasing on $[n, \infty)$, we can visualize the areas of the rectangles with the area under $f$ for $x \geq n$. 

![[Pasted image 20260629195030.png]]

We see that

$$
R_{n} = a_{n+1} + a_{n+2} + \cdots \leq \int_{n}^{\infty} f(x)\, dx
$$

and if we evaluate the height of the rectangles from the left-end points,

![[Pasted image 20260629195218.png]]


It's apparent that

$$
R_{n} = a_{n+1} + a_{n+2} + \cdots \geq \int_{n+1}^{\infty} f(x)\, dx
$$

So we have proved the following error estimate

> [!theorem] Remainder Estimate for the Integral Test
> Suppose $f(x) = a_{k}$, where $f$ is a continuous, positive, decreasing function for $x \geq n$ and $\sum a_{n}$ is convergent. If $R_{n} = s - s_{n}$, then $$ \int_{n+1}^{\infty} f(x) \, dx \leq R_{n} \leq \int_{n}^{\infty} f(x) \, dx  $$
> 
> If we add $s_{n}$ to each side of the inequality, we get $$ s_{n} + \int_{n+1}^{\infty} f(x)\, dx \leq s \leq s_{n} + \int_{n}^{\infty} f(x) \, dx  $$
