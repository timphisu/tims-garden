
# Ratio Test

We can test for convergence or divergence of a series by seeing how quickly terms are increasing or decreasing. Consider the ratio $\displaystyle \left| \frac{a_{n+1}}{a_{n}} \right|$. For a geometric series, we have that $|{a_{n+1}}/{a_{n}}| = |r|$ for all $n$. If $|r| < 1$, then the series converges; otherwise, it diverges. The following proof for this test lies in comparing a series to a geometric series.

> [!theorem] Ratio Test
> 1. If $\lim_{ n \to \infty } \left| \frac{a_{n+1}}{a_{n}} \right| = L < 1$, then the series is absolutely convergent, and therefore convergent. 
> 2. If $\lim_{ n \to \infty } \left| \frac{a_{n+1}}{a_{n}} \right| = L > 1$ or $L \to \infty$, then the series $\sum a_{n}$ is divergent.
> 3. If $\lim_{ n \to \infty } \left| \frac{a_{n+1}}{a_{n}} \right| = 1$, then the Ratio Test is inconclusive, that is, the test tells us nothing if the series is convergent or divergent.

**Proof:** 

*For part (1)*

Let $r$ be a real number such that $L < r < 1$. Then eventually for $n \geq N$,

$$
\left| \frac{a_{n+1}}{a_{n}} \right| < r \quad \text{when}\ n \geq N
$$

We can rearrange this to be 

$$
|a_{n+1}| < |a_{n}| r \quad \text{when}\ n \geq N
$$

If we take successive values of $n$ that make this inequality true. 

$$
\begin{align}
 & |a_{N+1}| < |a_{N}| r \\ \\
 & |a_{N+2}|  < |a_{N+1}|r < |a_{N}|r^{2} \\ \\
 & |a_{N+3}| < |a_{N+2}|r < |a_{N+1}| r^{2} < |a_{N}| r^{3} 
\end{align}
$$

And in general, 

$$
|a_{N+k}| < |a_{N}| r^{k} \quad \text{for}\ k = 1, 2, 3,...
$$

The right-hand sequence of this inequality can be made the series

$$
\sum_{k=1}^{\infty} |a_{N}|r^{k} \quad \text{or} \quad r \cdot \sum_{k=1}^{\infty} |a_{N}| r^{k-1}  
$$

We recognize this as a geometric series whose common ratio is $r$, and since $r < 1$, we know this series to be convergent. By the Direct Comparison Test, the series $\sum |a_{N+k}|$ is also convergent. Even though the inequality held only true for $n \geq N$, a finite number of terms does not affect convergence and as $k \to \infty$, this coincides with $n \to \infty$, so the series $\sum |a_{n}|$ is convergent. If the series is absolutely convergent, then the series in general is convergent.

*For part (2)*

If $|{a_{n+1}}/{a_{n}}| \to L > 1$ or $L \to \infty$, then for some integer $N$

$$
\left| \frac{a_{n+1}}{a_{n}} \right| > 1 \quad \text{whenever}\ n \geq N
$$

which after rearranging becomes

$$
|a_{n+1}|  > |a_{n}| \quad \text{whenever}\ n \geq N
$$

Since the absolute value of $a_{n}$ is increasing without any bound, this means that 

$$
\lim_{ n \to \infty } a_{n} \ne 0
$$

Therefore the series is divergent by the Test for Divergence.

*For part (3)*

This is less rigorous but is better shown with examples as to why the result of the Ratio Test being $L = 1$ is inconclusive. 

Consider the following series 

$$
\sum a_{n} = \sum_{n=1}^{\infty} \frac{1}{n} \quad \text{and} \quad \sum b_{n} = \sum_{n=1}^{\infty} \frac{1}{n^{2}}
$$

Applying the Ratio Test to $\sum a_{n}$, 

$$
\lim_{ n \to \infty } \left| \frac{a_{n+1}}{a_{n}} \right|  = \lim_{ n \to \infty } \frac{\frac{1}{n+1}}{\frac{1}{n}} = \lim_{ n \to \infty } \frac{n}{n+1} = \lim_{ n \to \infty } \frac{1}{1 + \frac{1}{n}} = \frac{1}{1+0} = 1
$$

and applying the same test to $\sum b_{n}$, 

$$
\lim_{ n \to \infty } \left| \frac{b_{n+1}}{b_{n}} \right| = \lim_{ n \to \infty } \frac{\frac{1}{(n+1)^{2}}}{\frac{1}{n^{2}}} = \lim_{ n \to \infty } \frac{n^{2}}{(n+1)^{2}} = \lim_{ n \to \infty } \left( \frac{n}{n+1} \right)^{2} = 1
$$

Even though both tests results in $L = 1$, we know that the series $\sum {1}/{n^{2}}$ converges while the series $\sum {1}/{n}$ diverges. So the test result is inconclusive. We have to use other tests.

> [!note]
> In general, the Ratio Test is conclusive if $a_{n}$ contains an exponential or factorial (it is the go-to method since it's very good at cancelling them out) but always fails for $p$-series.

---

**Problem:** Determine if the series

$$
\sum_{n=1}^{\infty} (-1)^{n-1} \frac{3^{n}}{2^{n}n^{3}}
$$

is convergent or divergent.

**Approach:** Applying the Ratio Test to this series,

> Applying the absolute value is just a matter of getting rid of $(-1)^{n}$ in $a_{n}$. If $a_{n}$ is always positive, then you can drop the absolute value notation. 

$$
\lim_{ n \to \infty } \left| \frac{a_{n+1}}{a_{n}} \right| = \lim_{ n \to \infty } \left[ \frac{3^{\cancel{ n }+1}}{2^{\cancel{ n }+1}(n+1)^{3}} \cdot \frac{\cancel{ 2^{n }}n^{3}}{\cancel{ 3^{n }}} \right] = \frac{3}{2} \lim_{ n \to \infty } \left( \frac{n}{n+1} \right)^{3} = \frac{3}{2}
$$

Since $\lim_{ n \to \infty } \left| {a_{n+1}}/{a_{n}} \right| = {3}/{2} > 1$, then the series diverges. 

---

**Problem:** Determine whether the series 

$$
\sum_{k=1}^{\infty} \frac{1}{k!} = \frac{1}{1} + \frac{1}{1\cdot2} + \frac{1}{1 \cdot 2 \cdot 3} + \cdots
$$

is convergent or divergent.

**Approach:** Using the Ratio Test on this series,

$$
\lim_{ k \to \infty } \left| \frac{a_{k+1}}{a_{k}} \right| = \lim_{ k \to \infty } \frac{1}{(k+1)!} \cdot \frac{k!}{1} = \lim_{ k \to \infty } \frac{k!}{(k+1)!}
$$

A useful property of factorials is that $(k+1)! = (k+1)k!$

So,

$$
\lim_{ k \to \infty } \frac{k!}{(k+1)!} = \lim_{ k \to \infty } \frac{\cancel{ k! }}{(k+1)\cancel{ k! }} = \lim_{ k \to \infty } \frac{1}{k+1} = \frac{1}{\infty} = 0 < 1
$$

This series then converges.

# Root Test

The Root Test is similar to the Ratio Test in that the following results determine similarly convergence or divergence. It's better suited for series when the $n$th term can be seen as $|a_{n}| = (b_{n})^{n}$ and we want to get rid of the $n$ cleanly. 

> [!theorem] Root Test
> 1. If $\displaystyle \lim_{  n \to \infty }\sqrt[n]{ |a_{n}|} = L < 1$, then the series $\sum a_{n}$ is absolutely convergent and is therefore convergent.
> 2. If $\displaystyle \lim_{ n \to \infty } \sqrt[n]{ |a_{n}| } = L > 1$, then the series $\sum a_{n}$ diverges.
> 3. If $\displaystyle \lim_{ n \to \infty } \sqrt[n]{ |a_{n}| } = L = 1$, the Root Test is inconclusive.

 When the Root Test fails for a series, it will also fail for the Ratio Test, and vice versa. 

**Problem:** Determine whether the series

$$
\sum_{n=2}^{\infty} \frac{(-1)^{n-1}}{(\ln n)^{n}}
$$

converges or diverges.

**Approach:** Applying the Root Test in this case yields

$$
\lim_{ n \to \infty } \left( |a_{n}|  \right) ^{1/n} = \lim_{ n \to \infty } \left( \frac{1}{(\ln n)^{n}} \right)^{1/n} = \lim_{ n \to \infty } \frac{1}{\ln n} = \frac{1}{\infty} = 0 < 1
$$

So the series converges. 

---

**Problem:** Determine whether the following series converges or diverges.

$$
\sum_{n=1}^{\infty} \left( 1 + \frac{1}{n} \right) ^{n^{2}}
$$

**Approach:** It's nice to use the Root Test to get rid of one power of $n$. 

$$
\lim_{ n \to \infty } (|a_{n}| )^{1/n} = \lim_{ n \to \infty } \left( 1 + \frac{1}{n} \right)^{n}
$$

This is a nice limit because we know the definition of $e$ is $\lim_{ n \to \infty } (1 + \frac{1}{n})^{n}$. 

So,

$$
\lim_{ n \to \infty } \left( 1 + \frac{1}{n} \right)^{n} = e \approx 2.71 > 1
$$

The series diverges by the Root Test.
