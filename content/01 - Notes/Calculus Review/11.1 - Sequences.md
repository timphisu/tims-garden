
# Sequences

> [!definition]
> An infinite sequence, or **sequence**, denoted $\{ a_{n} \}$, is an ordered list of numbers that can be thought of as a function whose domain is the set of natural numbers $\mathbb{Z} = \{ 1, 2, 3, ... \}$. For sequences that start with $n = 1$, their notation is $\{ a_{n} \}_{n=1}^{\infty}$ and its first term is $a_{1}$. 

## Limit of a Sequence

A sequence $\{ a_{n} \}$ has the limit $L$ and we write $$ \lim_{ n \to \infty } a_{n} = L \quad \text{or} \quad a_{n} \to L\ \text{as}\ n \to \infty$$ if we can make the terms $a_{n}$ as close to $L$ as we like be taking $n$ sufficiently large. If $\lim_{ n \to \infty } a_{n}$ exists, we say the sequence *converges* (or is convergent). Otherwise, we say the sequence *diverges* (or is divergent). 

> [!definition] Precise Definition of a Limit of a Sequence
> A sequence $\{ a_{n} \}$ has the limit $L$ and we write $$ \lim_{ n \to \infty } a_{n} = L \quad \text{or} \quad a_{n} \to L\ \text{as}\ n \to \infty$$ if for every $\epsilon > 0$, there is a corresponding integer $N$ such that if $n > N$ then $|a_{n} - L| < \epsilon$. 

This is similar to the epsilon-delta definition of a limit where you choose an $a_{N}$ that has a corresponding error, written $\epsilon = |a_{N} - L|$ (in the definition it's written the other way, but correspondence goes both ways), then the next term $a_{N+1}$, or written $a_{n}$ where $n > N$, will have a smaller error and thus will be closer to the limit $L$ as $n \to \infty$. That is, $|a_{n} - L| < |a_{N} - L|$.

A sequence can diverge if the terms do not approach a single number. We write $\lim_{ n \to \infty } a_{n} = \infty$ if the sequence blows up to infinity. To precisely define an infinite limit for sequences, for every positive number $M$, there is an integer $N$ such that if $n > N$, then $a_{n} > M$. We can write something similar for $\lim_{ n \to \infty } a_{n} = -\infty$. 

### Properties of Convergent Sequences

We can fit a sequence's $n$-th term $a_{n}$ through a continuous function $f(x)$, if $a_{n} = f(n)$. This helps us explore limits through continuous functions using previously known tools, such as l'Hospital's tool, and then conclude what the limit is for the sequence. 

> [!theorem]
> If $\lim_{ x \to \infty } f(x) = L$ and $f(n) = a_{n}$, when $n$ is an integer, then $\lim_{ n \to \infty } a_{n} = L$. 

#### Limit Laws for Sequences

Suppose that $\{ a_{n} \}$ and $\{ b_{n} \}$ are convergent sequences and $c$ is a constant. Then

$$
\begin{align}
 & \text{Sum Law} & \lim_{ n \to \infty } (a_{n} + b_{n}) = \lim_{ n \to \infty } a_{n} + \lim_{ n \to \infty } b_{n} \\ \\
 & \text{Difference Law} & \lim_{ n \to \infty } (a_{n} - b_{n}) = \lim_{ n \to \infty } a_{n} - \lim_{ n \to \infty } b_{n} \\ \\
 & \text{Constant Multiple Law} & \lim_{ n \to \infty } ca_{n} = c \lim_{ n \to \infty } a_{n} \\ \\
 & \text{Product Law} & \lim_{ n \to \infty } (a_{n}b_{n}) = \lim_{ n \to \infty } a_{n} \cdot \lim_{ n \to \infty } b_{n} \\ \\
 & \text{Quotient Law} & \lim_{ n \to \infty } \frac{a_{n}}{b_{n}} = \frac{\lim_{ n \to \infty } a_{n}}{\lim_{ n \to \infty } b_{n}} \quad \text{if} \quad b_{n} \ne 0
\end{align}
$$

> [!theorem] Squeeze Theorem for Sequences
> If $a_{n} \leq b_{n} \leq c_{n}$ for $n \geq n_{0}$ and $\lim_{ n \to \infty } a_{n} = \lim_{ n \to \infty } c_{n} = L$, then $\lim_{ n \to \infty } b_{n} = L$.


> [!theorem] Power Law
> If $p > 0$ and $a_{n} > 0$ then $$ \lim_{ n \to \infty } {a_{n}}^{p} = [\lim_{ n \to \infty } a_{n}]^{p}$$

**Proof:** The theorem implicitly states the limit does exist, so let $L = \lim_{ n \to \infty } a_{n}$. Since $a_{n} > 0\ \forall n$, there's no way the sequence could cross zero and converge to a negative limit. Hence, $L \geq 0$, which gives itself two cases to take care of.

*Case I: $L > 0$* 

Let $\epsilon$ be a small positive real number such that $0 < \epsilon < L$, which guarantees $L - \epsilon > 0$. By the definition of a limit (of a sequence), there's a corresponding (to $\epsilon$) integer $N$ such that for all $n > N$

$$
\begin{align}
 & |a_{n} - L| < \epsilon \\ \\
 & -\epsilon < a_{n} - L < \epsilon \\ \\
 & L - \epsilon < a_{n} < L + \epsilon
\end{align}
$$

All terms of the inequality are positive, so raising them to the power $p$ where $p > 0$ should still preserve the inequality.

$$
(L - \epsilon)^{p} < (a_{n})^{p} < (L + \epsilon)^{p} \quad \text{for all}\ n > N
$$

We define two constant sequences $a_{n}$ and $b_{n}$ such that $\lim_{ n \to \infty } a_{n} = (L - \epsilon)^{p}$ and $\lim_{ n \to \infty } b_{n} = (L - \epsilon)^{p}$. Taking the limit as $n \to \infty$,

$$
(L - \epsilon)^{p} < \lim_{ n \to \infty } (a_{n})^{p} < (L + \epsilon)^{p}
$$

Since the inequality holds for all $\epsilon > 0$, we can take the limit as $\epsilon \to 0^{+}$ across the entire constant inequality and get

$$
L^{p} < \lim_{ n \to \infty } (a_{n})^{p} < L^{p}
$$

By the Squeeze Theorem of Sequences, 

$$
\lim_{ n \to \infty } (a_{n})^{p} = L^{p}
$$

*Case II:* $L = 0$

For any $\epsilon > 0$, there exists an integer $N$ such that for all $n > N$, $|a_{n} - L| < \epsilon$. But $L = 0$, which simplifies this inequality to 

$$
0 < a_{n} < \epsilon
$$

Since $p > 0$, raising them to the power $p$ should maintain the inequality.

$$
0 < (a_{n})^{p} < \epsilon^{p}
$$

Defining two constant sequences $a_{n}$ and $b_{n}$ such that $\lim_{ n \to \infty } a_{n} = 0$ and $\lim_{ n \to \infty } b_{n} = \epsilon^{p}$. If we take the limit as $n \to \infty$,

$$
0 < \lim_{ n \to \infty } (a_{n})^{p} < \epsilon^{p} 
$$

Then since this inequality holds for all $\epsilon$, if we let $\epsilon \to 0^{+}$,

$$
0 < \lim_{ n \to \infty } (a_{n})^{p} < 0
$$

Which by the Squeeze Theorem implies

$$
\lim_{ n \to \infty } (a_{n})^{p} = 0 = 0^{p} = L^{p}
$$

Combining both cases, we can conclude that 

$$
\lim_{ n \to \infty } (a_{n})^{p} = L^{p} \quad \text{or} \quad \lim_{ n \to \infty } (a_{n})^{p} = \left[ \lim_{ n \to \infty } a_{n} \right] ^{p}
$$

> [!theorem] Absolute Value Theorem
> If $\lim_{ n \to \infty } |a_{n}| = 0$, then $\lim_{ n \to \infty } a_{n} = 0$.

We can pass sequences through functions and still arrive at the sequence's limit, stated by

> [!theorem]
> If $\lim_{ n \to \infty } a_{n} = L$ and the function $f$ is continuous at $L$, then $$ \lim_{ n \to \infty } f(a_{n}) = f(L) $$

which effectively allows us to pass limits through function arguments.

> [!theorem]
> The sequence $\{ r^{n} \}$ is convergent if $-1 < r \leq 1$ and divergent for all other values of $r$. $$ \lim_{ n \to \infty } r^{n} = \begin{cases} 0 & \text{if} & -1 < r < 1 \\ 1 & \text{if} & r = 1\end{cases} $$

**Proof:** We know that from the graphs of continuous function $f(x) = b^{x}$ that $\lim_{ x \to \infty } b^{x} = \infty$ if $b > 1$ and $\lim_{ x \to \infty } b^{x} = 0$ if $0 < b < 1$. It can be applied to our sequence $f(n) = a_{n} = r^{n}$ where $b = r$. It is self evident that $\lim_{ n \to \infty } 1^{n} = 1$ and $\lim_{ n \to \infty } 0^{n} = 0$. If $-1 < r < 0$ then $0 < |r| < 1$, which gives

$$
\lim_{ n \to \infty } |r|^{n} = \lim_{ n \to \infty } |r^{n}| = 0 
$$

#### Monotonic and Bounded Sequences

> [!definition]
> A sequence $\{ a_{n} \}$ is called **increasing** if $a_{n} < a_{n+1}$ for all $n \geq 1$. It is called **decreasing** if $a_{n} > a_{n+1}$ for all $n \geq 1$. A sequence is **monotonic** if it is increasing or decreasing.

We can show sequences are increasing by passing in $n+1$. 

For example, the sequence $\left\{  \frac{3}{n+5}  \right\}$ is decreasing because

$$
\frac{3}{n+5} > \frac{3}{n+6} = \frac{3}{(n+1) + 5}= a_{n+1}
$$

---

**Problem:** Show that the sequence $\displaystyle a_{n} = \frac{n}{n^{2} + 1}$ is decreasing.

We must show that $a_{n} > a_{n+1}$ is decreasing, that is,

$$
\frac{n}{n^{2} + 1} > \frac{n+1}{(n+1)^{2} + 1} \quad \text{for} \quad n \geq 1
$$

By cross-multiplying,

$$
\begin{align}
 & n[(n+1)^{2} + 1] > (n+1)(n^{2} + 1) \\ \\
 & n(n^{2} + 2n + 2) > n^{3} + n^{2} + n + 1 \\ \\
 & n^{3} + 2n^{2} + 2n > n^{3} + n^{2} + n + 1 \\ \\
 & n^{2} + n > 1
\end{align}
$$

And since $n \geq 1$, we know this inequality holds true.

> [!definition]
> A sequence $\{ a_{n} \}$ is **bounded above** if there is a number $M$ such that $a_{n} \leq M$ for all $n \geq 1$. A sequence is **bounded below** if there is a number $m$ such that $m \leq a_{n}$ for all $n \geq 1$. If a sequence is bounded above and below, then it is a called a **bounded sequence**.
> 

A sequence's bound $M$ does not automatically make it the sequence's limit $L$. Moreover, a sequence like $\lim_{ n \to \infty } a_{n} = n$ is bounded below $(a_{n} > 0)$ but not above. The sequence $a_{n} = {n}/{n+1}$ is bounded because $0 < a_{n} < 1$ for all $n$. 

> [!theorem] Monotonic Sequence Theorem
> Every bounded, monotonic sequence is convergent. In particular, a sequence that is increasing and bounded above converges, and a sequence that is decreasing and bounded below converges.

---

**Problem:** Find the limit of the sequence 

$$
\left\{ \sqrt{ 2 }, \sqrt{ 2\sqrt{ 2 } }, \sqrt{ 2\sqrt{ 2\sqrt{ 2 } } }, ... \right\}
$$

**Approach:** We realize this is a recursive sequence where 

$$
\left\{ \sqrt{ 2 }, \sqrt{ 2\sqrt{ 2 } }, \sqrt{ 2\sqrt{ 2 \sqrt{ 2 } } }, ... \right\} = \left\{ a_{1}, \sqrt{ 2a_{1} }, \sqrt{ 2a_{2} }, ... \right\}
$$

Hence, the recursive formula is

$$
a_{n+1} = \sqrt{ 2a_{n} },\quad \text{for} \quad n = 1, 2, 3, ...
$$

where $a_{1} = \sqrt{ 2 }$

Plugging a few values of $n$ into a calculator gives us something that's increasing from $\sqrt{ 2 }$ and approaches $2$. To prove this, we need to show with induction that the sequence is increasing, that is, $a_{n+1} > a_{n}$. 

If we let $n = k$, and assert our assumption:

$$
\begin{align}
 & a_{k+1} > a_{k} \\ \\
 & 2a_{k+1} > 2a_{k} \\ \\
 & \sqrt{ 2a_{k+1} } > \sqrt{ 2a_{k} } & \text{Positive Sq. Root} \\ \\
 & a_{k+2} > a_{k+1} 
\end{align}
$$

Hence, we've shown the inequality holds for the next term. Now we use induction to show that the sequence is bounded below $2$, that is $a_{n} < 2$ for all $n$. If we let $n=k$, 

$$
\begin{align}
 & a_{k} < 2 \\ \\
 & 2a_{k} < 4 \\ \\
 & \sqrt{ 2a_{k} } < 2 \\ \\
 & a_{k+1} < 2
\end{align}
$$

Hence, the next term will always be less than $2$. But that does not tell us what the limit of the sequence is, just that it exists by the Monotonic Sequence Theorem. As $n \to \infty$, we know that $a_{n} \to L$, but so will $a_{n+1} \to L$.

$$
\underbrace{ \lim_{ n \to \infty } a_{n+1} }_{ L } = \lim_{ n \to \infty } \sqrt{ 2a_{n} } = \sqrt{ 2\lim_{ n \to \infty }a_{n}  } = \sqrt{ 2L }
$$

Solving for $L$, we get

$$
L = \sqrt{ 2L } \to L^{2} = 2L \to L^{2} - 2L = 0 \to L(L-2) = 0 \to L = 0, 2
$$

We know that $a_{1} > 0$ but $a_{2} > a_{1}$ and so on for consecutive values of $n$. Therefore $L \ne 0$ and so $L = 2$.
