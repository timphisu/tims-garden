## Partial Functions

> [!definition]
> A *partial function* $f$ from a set $A$ to a set $B$ is an assignment to each element $a$ in a subset of $A$, called the *domain of definition of $f$*, of a unique element $b$ in $B$ . The sets $A$ and $B$ are called the *domain* and *codomain* of $f$, respectively. We say that $f$ is *undefined* for elements in $A$ that are not in the domain of definition of $f$. When the domain of definition of $f$ equals $A$, we say that $f$ is a *total function*

> Essentially this is saying we can restrict domains (excluding elements) so that the function *can* be defined.

### Examples of Partial Functions

1. The asymptotic function $\displaystyle f(x) = \frac{1}{x}$  is not defined at $x=0$ so the domain of the definition of the partial function $f$ excludes the zero and is defined as $\{ x \in R \ | \ x \ne 0 \}$ or in interval notation $(-\infty, 0)\cup(0, \infty)$. 

2. For the function $f : \mathbb{Z} \to \mathbb{R}$ where $f(n) = \sqrt{ n }$ is a partial function from $\mathbb{Z}$ to $\mathbb{R}$ where the domain of definition is the set of nonnegative integers. This is because $f$ is undefined for negative integers.
