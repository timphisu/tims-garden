For some functions the range and codomain are equal. That is, every member of the codomain is the image of some element of the domain. Functions with this property are called **onto** functions. 

> [!definition]
> A function $f$ from $A$ to $B$ is called *onto*, or a *surjection*, if and only if for every element $b \in B$ there is an element $a \in A$ with $f(a) = b$. 

#### Examples of Onto Functions

1. Let $f$ be the function from $\{ a, b, c, d \}$ to $\{ 1, 2, 3 \}$ defined by $f(a) = 3$, $f(b) = 2$, $f(c) = 1$, and $f(d) = 3$. Is $f$ an onto function?

	Since every element of the codomain are images of elements in the domain, we see that $f$ is onto. 

2. Is the function $f : \mathbb{Z} \to \mathbb{Z}$  where $f(x) = x^2$ onto?

	This function is not onto as a counterexample there is no $x$ for $x^2 = -1$
