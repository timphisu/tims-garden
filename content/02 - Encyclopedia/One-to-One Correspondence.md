> [!definition]
> The function $f$ is a *one-to-one correspondence*, or a *bijection*, if it is both one-to-one and onto. 

A special case can happen where if a function maps elements from the finite set $A$ to the same set. Then the function is one-to-one if and only if the function is onto.
